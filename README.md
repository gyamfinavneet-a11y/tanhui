# 林碳预评

遥感林业碳汇**立项前预评估**平台的演示网站。北京科技大学第二十八届"摇篮杯"创意竞赛（经管赛区）参赛作品。

- 面向林农：先算清一片林子值不值得做碳汇项目，再决定要不要请公司开发。
- 演示区：河北张家口崇礼冬奥赛区。
- 整个网站只有一个文件 `index.html`，不依赖服务器和外部资源，直接用浏览器打开即可。

## 说明

- 每亩碳汇量取自《造林碳汇方法学》V02 表 A.3 的缺省值；样地数和"少打多扣"比较依据 V02 表 A.2。
- 崇礼案例页的结果由 Google Earth Engine 上的 Landsat、Sentinel-2、GEDI 数据计算得到。
- 林农报名、林业站后台中的村名、人数、电话均为**演示数据**，页面上已标注。
- 遥感估算仅供立项前参考，不构成交易依据。
