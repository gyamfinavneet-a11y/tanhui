## 上传 GitHub

将本文件夹内的 `index.html` 和 `README.md` 上传到用于部署网站的仓库根目录，使仓库根目录可以直接看到 `index.html`。

如果原仓库已经有首页，先保留旧版本，再用这里的 `index.html` 更新。不要只把整个“最新网站”文件夹放进仓库根目录，导致首页藏在子目录里。

沿用原有 GitHub → Vercel 部署链路即可；本文件夹不含账号、密钥或部署授权，本次未代为上传或修改线上网站。
