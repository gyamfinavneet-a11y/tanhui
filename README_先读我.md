# 碳瞰网站 v2 · 推 GitHub 用

这个包只含网站文件，用来更新线上站点（https://tanhui.lxqkiki.asia）。

## 推之前先看这条

- **`index.html` = v2 新版**（首页四幕、区间条、战绩条那套）。直接把这个包的内容推到 GitHub 仓库，线上就会变成 v2。
- `index_原版备份_1125.html` 是 11-25 的旧版首页，留作对照，**不要推成 index.html**。
- `原型v2_全站.html` 和 `index.html` 内容相同，只是保留原名方便对照。

## 包里有什么

| 文件 | 作用 |
|---|---|
| `index.html` | 新版首页（v2），部署入口 |
| `林农端.html` / `林业局端.html` | 两个分端演示页 |
| `二维码_带标题.png` / `二维码_纯码.png` | 现场扫码用 |
| `发布包/` | 旧的发布副本，可忽略 |
| `docs/` | 深化方案、打磨记录、构建脚本、部署说明——**不参与部署**，只是留档 |

## 两个提醒

1. v2 是断网可开的纯静态页（外部请求 0 个），推 GitHub Pages / Vercel 都能直接跑。
2. 站名现已统一用"碳瞰"（v2 里就是它）。`网站改版方案` 里旧的"林碳预评"说法已过时。

原版项目文件一个字没动；完整的全部比赛文件包在桌面的 `原摇篮杯_全部比赛文件_20261126.zip`。
